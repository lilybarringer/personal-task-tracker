
# Personal Task Tracker

## Project Description
The Personal Task Tracker is a simple web application that helps users organize their daily tasks. Users can add tasks, mark them as completed, and delete tasks when they are finished.

## How to Run/View the Project
1. Download or clone this repository from GitHub.
2. Open the project folder.
3. Open the index.html file in a web browser.
4. Enter a task and click Add Task to get started.

## Main Features
- Add new tasks.
- Mark tasks as completed.
- Delete tasks.
- Display the number of remaining tasks.
- Simple and user-friendly design.
